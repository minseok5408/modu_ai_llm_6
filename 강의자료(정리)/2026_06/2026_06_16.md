# 1. 오늘 강의 개요

가상의 `council.txt`가 아니라 실제 국회 회의록 PDF/CSV 데이터를 GraphRAG 프로젝트로 만든다.

```text
CSV/PDF 원본
  ↓
pdfplumber TXT 추출
  ↓
회의록 전처리
  ↓
GraphRAG input 구성
  ↓
settings.yaml 도메인 설정
  ↓
indexing
  ↓
artifact 분석 + query + 평가
```

# 5. 회의록 텍스트 전처리

페이지 번호, 불필요한 장식, 발언자 표시를 정리한다.

```python
def preprocess_assembly_text(raw_text):
    lines = raw_text.split("\n")
    cleaned = []

    for line in lines:
        line = line.strip()
        if not line:
            cleaned.append("")
            continue

        if re.match(r"^제\d+회.+\d+$", line):
            continue
        if re.match(r"^\d{1,3}$", line):
            continue
        if re.match(r"^[·...]+$", line):
            continue

        line = re.sub(r"^◯(\S+)\s+(\S+)", r"[\1 \2]", line)
        cleaned.append(line)

    text = "\n".join(cleaned)
    text = re.sub(r"\n{3,}", "\n\n", text)
    return text
```

# 6. input 파일 생성

GraphRAG input 폴더에 전처리된 회의록을 넣는다.

input_dir = PROJECT_ROOT / "input"

# 11. 그래프 구조 진단

GraphML snapshot을 읽어 노드/엣지 수, 평균 degree, density, isolate를 확인한다.

```python
import networkx as nx

graphml_files = list(OUTPUT.rglob("*.graphml"))
g = nx.read_graphml(graphml_files[0])

n_nodes = g.number_of_nodes()
n_edges = g.number_of_edges()

avg_degree = 2 * n_edges / n_nodes
density = nx.density(g)
n_isolates = len(list(nx.isolates(g)))
```

```text
고립 노드(degree=0)가 너무 많다:
  관계 추출이 부족할 수 있음

평균 degree가 너무 낮다:
  엔티티 간 연결성이 약할 수 있음

커뮤니티 크기가 극단적으로 치우친다:
  chunking 또는 entity 정규화 문제 가능
```

# 12. 엔티티 추출 품질 평가

원본 chunk와 추출된 entity를 LLM-as-a-Judge로 평가한다.

```python
from openai import OpenAI
client = OpenAI()


def evaluate_entity_extraction(chunk_text, extracted_entities, model="gpt-4o-mini"):
    entity_list = "\n".join(
        f"- {row['title']} ({row['type']}) : {row.get('description', 'N/A')[:100]}"
        for _, row in extracted_entities.iterrows()
    )

    prompt = f"""당신은 한국어 텍스트에서 엔티티 추출 품질을 평가하는 전문가입니다.

### 텍스트
{chunk_text[:2000]}

### 시스템이 추출한 엔티티
{entity_list if entity_list.strip() else "(없음)"}

다음 JSON 형식으로 응답하세요:
{{
  "precision_score": 0.0,
  "recall_score": 0.0,
  "false_positives": [],
  "false_negatives": [],
  "type_accuracy": 0.0,
  "reasoning": "..."
}}"""

    response = client.chat.completions.create(
        model=model,
        messages=[{"role": "user", "content": prompt}],
        temperature=0,
        response_format={"type": "json_object"},
    )
    return json.loads(response.choices[0].message.content)
```

# 13. 평가 질문 자동 생성

커뮤니티 리포트를 기반으로 local/global 평가 질문을 자동 생성한다.

```python
def generate_eval_questions(reports_df, n_local=5, n_global=3, model="gpt-4o-mini"):
    report_summaries = "\n\n".join(
        f"[커뮤니티: {row['title']}]\n{row['summary']}"
        for _, row in reports_df.iterrows()
    )

    prompt = f"""아래는 국회 과방위 회의록 분석 결과의 커뮤니티 요약입니다.

{report_summaries}

평가용 질문을 생성하세요.

Local Search용 질문 {n_local}개:
특정 인물·조직·법안에 대한 구체적 질문.

Global Search용 질문 {n_global}개:
전체 회의록을 종합해야 답할 수 있는 거시 질문.

JSON 형식:
{{
  "local_questions": [],
  "global_questions": []
}}"""

    response = client.chat.completions.create(
        model=model,
        messages=[{"role": "user", "content": prompt}],
        temperature=0.7,
        response_format={"type": "json_object"},
    )
    return json.loads(response.choices[0].message.content)
```

# 14. 답변 품질 평가

질문 → GraphRAG 답변 → LLM-as-a-Judge 평가 흐름이다.

| 차원 | 설명 | 점수 |
|------|------|------|
| faithfulness | 답변이 원본 데이터에 근거하는가 | 1~5 |
| relevance | 질문에 직접 답하는가 | 1~5 |
| completeness | 중요 측면을 빠짐없이 다루는가 | 1~5 |
| coherence | 구조적이고 읽기 쉬운가 | 1~5 |

```python
def evaluate_answer(question, answer, model="gpt-4o-mini"):
    prompt = f"""당신은 RAG 시스템의 답변 품질을 평가하는 전문가입니다.

### 질문
{question}

### 시스템 답변
{answer}

각 항목을 1~5로 평가하세요:
- faithfulness
- relevance
- completeness
- coherence

JSON 형식:
{{
  "faithfulness": 1,
  "relevance": 1,
  "completeness": 1,
  "coherence": 1,
  "reasoning": "..."
}}"""

    response = client.chat.completions.create(
        model=model,
        messages=[{"role": "user", "content": prompt}],
        temperature=0,
        response_format={"type": "json_object"},
    )
    return json.loads(response.choices[0].message.content)
```

# 15. 개선 전략

| 문제 | 원인 | 해결책 |
|------|------|--------|
| 재현율 낮음 | 청크 큼 / 글리닝 부족 | `chunking.size` 감소, `max_gleanings` 증가 |
| 정밀도 낮음 | 도메인 안 맞는 유형 | `entity_types` 조정 |
| 고립 노드 많음 | 관계 추출 부족 | 프롬프트에 관계 강조 |
| Local 답변 불완전 | 참조 chunk 부족 | `local_search.text_unit_prop` 증가 |
| Global 답변 피상적 | 커뮤니티 리포트 짧음 | `community_reports.max_length` 증가 |

```text
인덱싱 -> 평가 -> 진단 -> 설정 조정 -> 재인덱싱 -> 재평가
```
