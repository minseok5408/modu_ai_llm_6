# 2. LangGraph vs LangChain

```text
[LangChain]
  chain = prompt | retriever | llm | parser
  → 파이프(|) 연산자로 선형(직선) 연결
  → 분기, 반복, 상태 공유가 어렵다

[LangGraph]
  노드(node) : 함수 (search, find, answer, ...)
  엣지(edge) : 노드들을 연결하는 화살표
  상태(state): 그래프 전체에서 공유하는 딕셔너리
  → 비선형 흐름(분기, 반복, 사이클) 가능
  → 상태가 노드 사이를 자동으로 전달됨
```

### 비유

```text
LangChain = 공장 컨베이어 벨트 (한 방향으로만 진행)
LangGraph  = 공장 전체 라인 (분기, 피드백, 재작업 가능)
```

# 3. 핵심 개념 — 노드, 엣지, 상태(State)

```text
노드(Node):
  - 그래프의 각 처리 단계
  - 파이썬 함수로 작성
  - 입력: 현재 state (dict)
  - 출력: 업데이트할 키-값 (dict)

엣지(Edge):
  - 노드 사이의 연결선
  - 일반 엣지: A → B (항상 B로)
  - 조건부 엣지: A → 조건 → B 또는 C

상태(State):
  - 그래프 전체에서 공유하는 딕셔너리
  - TypedDict로 타입 정의
  - 노드가 반환하는 딕셔너리로 덮어씌워짐 (기본값)
```

# 4. TypedDict로 State 정의

```python
from typing import TypedDict
```

```python
    # 업데이트할 키만 반환 (나머지는 그대로 유지됨)
    return {'key': new_value}
```

# 5. StateGraph 기본 패턴

### 최소 예제

```python
class MiniState(TypedDict):
    text: str

def upper_node(state: MiniState) -> dict:
    return {"text": state['text'].upper()}

def excite_node(state):
    return {"text": state['text'] + '!'}

builder = StateGraph(MiniState)
builder.add_node('upper', upper_node)
builder.add_node('excite', excite_node)
builder.add_edge(START, 'upper')
builder.add_edge('upper', 'excite')
builder.add_edge('excite', END)

app = builder.compile()
app.invoke({'text': 'hello'})
# → {'text': 'HELLO!'}
```

### StateGraph 생성 단계

```text
1. StateGraph(StateClass) — 상태 타입 지정
2. builder.add_node(name, fn) — 노드 등록
3. builder.add_edge(from, to) — 엣지 연결
4. builder.compile() — 앱 빌드
5. app.invoke({'state_key': initial_value}) — 실행
```

# 6. 다중 노드 직렬 연결

```python
class DocState(TypedDict):
    raw       : str
    cleaned   : str   # strip()
    translated: str   # upper()
    summary   : str   # [:5]
    log       : str

def clean(state: DocState) -> dict:
    return {'cleaned': state['raw'].strip(), 'log': state['log'] + 'clean,'}

def translate(state: DocState) -> dict:
    return {'translated': state['cleaned'].upper(), 'log': state['log'] + 'translate,'}

def summarize(state: DocState) -> dict:
    return {'summary': state['translated'][:5], 'log': state['log'] + 'summarize,'}

builder = StateGraph(DocState)
for n, fn in [('clean', clean), ('translate', translate), ('summarize', summarize)]:
    builder.add_node(n, fn)

builder.add_edge(START, 'clean')
builder.add_edge('clean', 'translate')
builder.add_edge('translate', 'summarize')
builder.add_edge('summarize', END)
app = builder.compile()

app.invoke({"raw": "  hello langgraph world  ", "cleaned": "", "translated": "", "summary": "", "log": ""})
# → {'raw': '  hello langgraph world  ',
#    'cleaned': 'hello langgraph world',
#    'translated': 'HELLO LANGGRAPH WORLD',
#    'summary': 'HELLO',
#    'log': 'clean,translate,summarize,'}
```

> 각 노드는 자신이 담당하는 키만 업데이트한다  
> 나머지 키는 이전 상태 그대로 유지된다

# 7. LLM을 노드로 사용

```python
class QAState(TypedDict):
    question: str
    answer  : str

def llm_answer(state: QAState) -> dict:
    response = llm.invoke([HumanMessage(content=state['question'])])
    return {'answer': response.content}

builder = StateGraph(QAState)
builder.add_node('llm_answer', llm_answer)
builder.add_edge(START, 'llm_answer')
builder.add_edge('llm_answer', END)
app = builder.compile()

app.invoke({'question': 'langgraph를 한 문장으로?', 'answer': ''})
# → {'question': '...', 'answer': 'LangGraph는 ...'}
```

### 번역 노드 예시

```python
class TransState(TypedDict):
    ko: str
    en: str

def translate(state: TransState) -> dict:
    response = llm.invoke([
        SystemMessage(content='translate to english, only english'),
        HumanMessage(content=state['ko'])
    ])
    return {'en': response.content}

app.invoke({"ko": "오늘 날씨가 좋네요.", "en": ""})
# → {'ko': '오늘 날씨가 좋네요.', 'en': 'The weather is nice today.'}
```

# 8. add_conditional_edges — 조건 분기

라우터 함수가 반환하는 문자열에 따라 다른 노드로 분기한다.

### 기본 패턴

```python
def router_fn(state) -> str:
    # 조건에 따라 다음 노드 이름(문자열) 반환
    return "node_a" if ... else "node_b"

builder.add_conditional_edges(
    '시작노드',
    router_fn,
    {'node_a': 'node_a', 'node_b': 'node_b'}  # 반환값 → 노드 이름 매핑
)
```

### 짝수/홀수 분기 예시

```python
class NumberState(TypedDict):
    n    : int
    label: str

def parity_router(state) -> str:
    return "even" if state['n'] % 2 == 0 else 'odd'

def even_handler(state): return {'label': f"{state['n']}은(는) 짝수입니다"}
def odd_handler(state):  return {'label': f"{state['n']}은(는) 홀수입니다"}
def start_n(state):      return {}

b = StateGraph(NumberState)
b.add_node('start_n', start_n)
b.add_node('even_handler', even_handler)
b.add_node('odd_handler',  odd_handler)

b.add_edge(START, 'start_n')
b.add_conditional_edges(
    'start_n', parity_router,
    {'even': 'even_handler', 'odd': 'odd_handler'}
)
b.add_edge('even_handler', END)
b.add_edge('odd_handler',  END)
app = b.compile()

app.invoke({'n': 7, 'label': ''})   # → {'n': 7, 'label': '7은(는) 홀수입니다'}
app.invoke({'n': 8, 'label': ''})   # → {'n': 8, 'label': '8은(는) 짝수입니다'}
```

### 3단계 분기 (성적 등급)

```python
class GradeState(TypedDict):
    score: int
    grade: str

def grade_router(state) -> str:
    if state['score'] >= 90: return 'a'
    if state['score'] >= 70: return 'b'
    return 'c'

def grade_a(state): return {'grade': 'A'}
def grade_b(state): return {'grade': 'B'}
def grade_c(state): return {'grade': 'C'}
def start_grade(state): return {}

b = StateGraph(GradeState)
b.add_node('start_grade', start_grade)
b.add_node('grade_a', grade_a)
b.add_node('grade_b', grade_b)
b.add_node('grade_c', grade_c)

b.add_edge(START, 'start_grade')
b.add_conditional_edges(
    'start_grade', grade_router,
    {'a': 'grade_a', 'b': 'grade_b', 'c': 'grade_c'}
)
for n in ['grade_a', 'grade_b', 'grade_c']:
    b.add_edge(n, END)
app = b.compile()

for s in [95, 75, 50]:
    print(app.invoke({'score': s, 'grade': ''}))
# {'score': 95, 'grade': 'A'}
# {'score': 75, 'grade': 'B'}
# {'score': 50, 'grade': 'C'}
```

# 9. 여러 분기 합치기 (merge 노드)

```python
class QuestionState(TypedDict):
    question: str
    qtype   : str
    answer  : str

def classify(state):
    q = state['question'].lower()
    if '?' not in q:                              return {'qtype': 'statement'}
    if any(w in q for w in ['언제', 'when']):    return {'qtype': 'when'}
    if any(w in q for w in ['어디', 'where']):   return {'qtype': 'where'}
    return {'qtype': 'what'}

def h_when(state):  return {'answer': '[시간] 답변'}
def h_where(state): return {'answer': '[장소] 답변'}
def h_what(state):  return {'answer': '[일반] 답변'}
def h_stmt(state):  return {'answer': '[진술문] 검색 불필요'}
def merge(state):   return {'answer': state['answer'] + '!!!!!!!'}

b = StateGraph(QuestionState)
b.add_node('classify', classify)
for name, fn in [('h_when', h_when), ('h_where', h_where), ('h_what', h_what), ('h_stmt', h_stmt)]:
    b.add_node(name, fn)
b.add_node('merge', merge)

b.add_edge(START, 'classify')
b.add_conditional_edges(
    'classify', lambda s: s['qtype'],
    {'when': 'h_when', 'where': 'h_where', 'what': 'h_what', 'statement': 'h_stmt'}
)
for n in ['h_when', 'h_where', 'h_what', 'h_stmt']:
    b.add_edge(n, 'merge')
b.add_edge('merge', END)
app = b.compile()

app.invoke({'question': "회의 어디서 해?", 'qtype': '', 'answer': ''})
# → {'question': '회의 어디서 해?', 'qtype': 'where', 'answer': '[장소] 답변!!!!!!!'}
```

# 10. 핵심 개념 총정리

### StateGraph API 정리

| 메서드 | 역할 |
|--------|------|
| StateGraph(StateClass) | 그래프 생성 |
| .add_node(name, fn) | 노드 추가 |
| .add_edge(from, to) | 일반 엣지 추가 |
| .add_conditional_edges(from, router, map) | 조건부 엣지 추가 |
| .compile() | 실행 가능한 앱으로 빌드 |
| app.invoke(state) | 그래프 실행 |

### 전체 흐름 다이어그램

```text
초기 상태 dict
    ↓
START
    ↓
노드 A (state 읽기 → dict 반환 → state 업데이트)
    ↓
[조건부] 라우터 → 노드 B 또는 노드 C
    ↓
merge 노드 (여러 분기 합치기)
    ↓
END
    ↓
최종 state dict 반환
```

# 11. 자주 나오는 실수/주의사항

### 실수 1: 노드에서 state 전체를 반환

```python
# 틀린 코드 → state 전체를 반환하면 의도치 않은 덮어쓰기 발생
def my_node(state):
    state['key'] = new_value
    return state   # 전체 반환

# 올바른 코드 → 업데이트할 키만 반환
def my_node(state):
    return {'key': new_value}
```

### 실수 2: add_edge(START, ...) 없이 compile

```python
# START 노드에서 출발하는 엣지가 없으면 에러
# 반드시 builder.add_edge(START, '첫번째노드') 필요
```

### 실수 3: 조건부 엣지의 반환값과 매핑 불일치

```python
# router 함수가 'even'을 반환하는데 매핑에 'even' 없으면 에러
b.add_conditional_edges(
    'start', parity_router,
    {'Even': 'even_handler', 'odd': 'odd_handler'}  # 'Even'은 대문자 → 매핑 불일치
)

# 올바른 코드
b.add_conditional_edges(
    'start', parity_router,
    {'even': 'even_handler', 'odd': 'odd_handler'}
)
```

### 실수 4: 분기된 노드에서 END 엣지 빠뜨리기

```python
# 모든 말단 노드에 .add_edge(node, END) 필요
# 하나라도 빠지면 해당 분기에서 그래프가 종료되지 않음
for n in ['grade_a', 'grade_b', 'grade_c']:
    b.add_edge(n, END)   # 반드시 모두 추가
```

### 실수 5: invoke의 초기값에 State의 모든 키 제공 안 함

```python
# TypedDict의 모든 키에 초기값 필요
# 일부 키 없으면 노드 실행 시 KeyError
app.invoke({'score': 85})           # grade 키 없음 → 에러
app.invoke({'score': 85, 'grade': ''})  # 올바른 코드
```
